Dérive du travail du moteur

Le travail exécuté, jalon par jalon

Les trois séries partagent la même unité et la même échelle. Une interruption de la courbe signale un jalon dont la valeur est inconnue : elle n'est pas interpolée.

Variation d'un jalon au suivant, sur …

Une barre vers le bas est un gain — moins de travail qu'au jalon précédent. Vers le haut, un coût réel. Les plus gros écarts sont annotés ; toutes les valeurs sont dans le tableau.

Toutes les valeurs

Le compte d'instructions est déterministe et indifférent à l'adresse du code comme au cache : il mesure le travail, là où un temps d'exécution varie de ±7 % selon la seule disposition du code machine. Il se relève avec bash bench/icount.sh <réf> [<réf>]. Un jalon par journée mesure l'état en fin de journée : l'écart affiché cumule tous les commits du jour, et le sujet indiqué — celui du dernier — n'en porte ni le mérite ni le blâme. La borne basse de la série n'est pas l'historique git mais le langage : avant le 20 juin 2026, ces trois scripts ne s'exécutent pas.

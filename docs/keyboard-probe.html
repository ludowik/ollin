The way the engine would do it


A game does not receive a tap inside the tap handler: it sees it in its NEXT animation frame. These two boxes ask for the keyboard the same way. On iPhone, the first round showed that this plain request is refused, so tests 8 and 9 below try a trick: take the focus inside a first tap WITHOUT a keyboard, then let the boxes ask for the keyboard later.
